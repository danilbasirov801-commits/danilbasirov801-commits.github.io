# Портфолио веб-разработчика

Многостраничный сайт-портфолио на чистом HTML, CSS и JavaScript.
Без фреймворков, без сборки, без внешних зависимостей — работает
на любом хостинге и даже без интернета (кроме шрифтов).

## Метрики и аналитика (когда будут коды)

1. Откройте `js/metrics.js` — там инструкция и место для кода
   Яндекс.Метрики (вставляется целиком в функцию `initMetrics`).
2. Для Google Analytics добавьте строки gtag.js в `<head>` страниц
   или подключите их через `loadScript()` в том же файле.
3. В `<head>` каждой страницы есть закомментированный блок
   `МЕТРИКИ` — можно вставлять коды прямо туда.

Больше ничего менять не нужно: подключение `js/metrics.js` уже есть
на всех страницах.

## SEO — что уже сделано

- У каждой страницы свои `title` и `description`.
- Canonical-ссылки, Open Graph и Twitter Card для красивых превью в соцсетях.
- Разметка JSON-LD: Person/WebSite на главной, BreadcrumbList + CreativeWork в кейсах.
- `robots.txt` и `sitemap.xml`.
- Семантика: один `<h1>` на страницу, alt у картинок, aria-подписи у кнопок.
- Быстрая загрузка: `defer` у скриптов, `loading="lazy"` и размеры у картинок.

## Фишки

- **Живой 3D-фон**: медленно вращающиеся каркасные куб и октаэдр на Canvas
  (без библиотек), с перспективой, свечением вершин и параллаксом за курсором.
  Вокруг — звёздная пыль, дрейфующие аврора-свечения, а в тёмной теме изредка
  падают звёзды. Сверху — тонкое «зерно плёнки» (CSS). Цвет автоматически
  берётся из темы; при «уменьшить анимацию» рисуется один статичный кадр.
  Хотите изменить сцену — всё в `js/bg3d.js`.
- Тёмная/светлая тема (запоминается, подстраивается под систему).
- Переключатель RU/EN (работает через CSS — без «мигания» при загрузке).
- Анимации: появление при прокрутке, вход героя, бегущая строка технологий —
  всё отключается, если у посетителя включено «уменьшить анимацию».
- Фильтры проектов, копирование контактов, кнопка «наверх».
- Без JS сайт полностью читается: тексты видны всегда.
